# Smart Printer System

This project monitors and manages printers in your network.

## Features

- Lists printers and their IP addresses (see `print-monitor/printers.json`)
- Easily add or update printer information

## Getting Started

1. **Clone the repository:**
   ```
   git clone https://github.com/ThebeLedwaba/smartPrinterSystem.git
   ```

2. **Navigate to the project folder:**
   ```
   cd smartPrinterSystem
   ```

3. **View or edit printers:**
   - Printer details are stored in `print-monitor/printers.json`.

## Example printers.json

```json
[
  { "name": "IT Printer 1", "ip": "192.168.0.101" },
  { "name": "Automation Printer 2", "ip": "192.168.0.102" },
  { "name": "Warehouse Printer", "ip": "192.168.0.103" }
]
```
